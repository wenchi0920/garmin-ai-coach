# Running Garmin AI Coach - 專屬科學化訓練計畫書 (Wenchi)

## 1. 系統核心定位

Garmin AI Coach 是一個整合運動生理學、穿戴裝置數據分析與個人化動態課表排程的專業馬拉松訓練系統。本系統以「數據驅動，精確校準，無痛增長」為核心理念，每日自動讀取並解析跑者 Garmin 穿戴裝置數據（包括 `.fit` 運動檔案、靜息心率 RHR、身體能量 Body Battery、壓力指數 Stress、睡眠分數與 HRV 心率變異度等）。透過個人化動態跑力 (VDOT) 的精準校準，設定輕鬆跑 (E)、馬拉松配速 (M)、乳酸門檻 (T) 與間歇跑 (I) 之配速與心率區間，在生理超載刺激與超補償修復之間取得黃金平衡。系統同時具備防傷避險與疲勞監控機制，協助跑者在安全無痛的前提下超越極限，順利達成目標賽事完賽里程碑。
