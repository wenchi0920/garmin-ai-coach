# Running Garmin AI Coach - 專屬科學化訓練計畫書 (Wenchi)

## 1. 系統核心定位

Garmin AI Coach 是一個結合運動生理學、穿戴裝置數據分析與自動化週期課表排程的專業馬拉松訓練系統。本系統以「數據驅動，精確校準，無痛增長」為核心理念，每日自動讀取並解析跑者 Garmin 965 穿戴裝置數據（包含 `.fit` 運動檔案、靜息心率 RHR、身體能量 Body Battery、壓力指數 Stress、睡眠分數與 HRV 心率變異度等）。透過個人化動態跑力 (VDOT) 的精準校準，自動計算輕鬆跑 (E)、馬拉松配速 (M)、乳酸門檻 (T) 與間歇跑 (I) 之配速與心率區間，在生理超載刺激與超補償修復之間取得黃金平衡。系統同時整合每週防傷避險與疲勞監控機制，協助跑者在安全無痛的前提下超越極限，順利達成目標賽事完賽里程碑。

## 📅 4. 本週訓練重點 (W33 - 科學減量第一週)

本週（2026-08-10 ~ 2026-08-16）為「2026 第 W33 週」，正式進入雪梨馬拉松備戰的**「科學減量第一週 (Taper Phase 1)」**（單週目標 32km）。以下為本週訓練的四大核心項目：

* **一、 訓練重點：適度下調跑量，保留強度與配速感**
  單週總跑量調降至 32km（下調約 28%），降低身體累積的疲勞，同時保持短距離 T 門檻 (6'07"/km) 節奏練習，讓神經肌肉系統維持活絡。

* **二、 核心賽事：富士山 TATTA RUN 半馬線上賽完賽**
  利用週六的 **13km LSD** 戶外跑（GPS 記錄），一舉補齊剩餘里程，順利完成 2026 富士山馬拉松之途 TATTA RUN 半馬線上錦標賽。

* **三、 關鍵課表：13km 減量長跑與 4km T門檻節奏練習**
  1. **週一 (08/10)**：5km Z1/Z2 恢復跑 + 上半身重訓 + 睡前瑜伽。
  2. **週二 (08/11)**：8km T 門檻跑（2km 暖身 + **4km T配速 6'07"/km** + 2km 緩跑） + 跑者核心穩定。
  3. **週四 (08/13)**：6km Z2 基礎有氧跑（1km 暖身 + 4km Z2 基礎有氧 + 1km 緩跑） + 下半身重訓。
  4. **週六 (08/15)**：13km LSD 戶外長跑（**必須戶外 GPS**，1km 暖身 + 11km Z2 有氧慢跑 + 1km 緩跑）。

* **四、 執行建議：高步頻 170+ 與充沛睡眠**
  跑步過程中將步頻鎖定在 **170-175 spm**，保持輕快落地的體感。減量期請每晚於 23:00 前躺平入睡，讓 Body Battery 充分充能。
