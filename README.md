# Running Garmin AI Coach - 專屬科學化訓練計畫書 (Wenchi)

## 1. 系統核心定位

Garmin AI Coach 是一個結合運動生理學、穿戴裝置數據分析與自動化週期課表排程的專業馬拉松訓練系統。本系統以「數據驅動，精確校準，無痛增長」為核心理念，每日自動讀取並解析跑者 Garmin 965 穿戴裝置數據（包含 `.fit` 運動檔案、靜息心率 RHR、身體能量 Body Battery、壓力指數 Stress、睡眠分數與 HRV 心率變異度等）。透過個人化動態跑力 (VDOT) 的精準校準，自動計算輕鬆跑 (E)、馬拉松配速 (M)、乳酸門檻 (T) 與間歇跑 (I) 之配速與心率區間，在生理超載刺激與超補償修復之間取得黃金平衡。系統同時整合每週防傷避險與疲勞監控機制，協助跑者在安全無痛的前提下超越極限，順利達成目標賽事完賽里程碑。

## 📅 4. 本週訓練重點 (W32)

本週（2026-08-03 ~ 2026-08-09）為「2026 第 W32 週」，正式進入雪梨馬拉松備戰的**「巔峰挑戰期第二週 (Peak Phase 2)」**，也是單週總跑量封頂的最後一週（單週目標 45km）。以下為本週訓練的五大核心項目詳盡解析：

* **一、 訓練重點：單週跑量封頂與耐力極限突破**
  本週是雪梨馬拉松前負荷最重的一週。訓練核心在於「鞏固 T 門檻跑的乳酸耐受力，並安全無痛地完成 20km LSD 戶外長跑，觸及單週 45km 跑量上限」。本週將重點加強下坡離心控制與高步頻維持，確保在最大訓練量下肌肉與關節不出現異常緊繃，為下週開始的科學減量與超補償創造完美的起點。
  
* **二、 核心目標：富士山馬拉松之途 TATTA RUN 累積賽事啟動與 20km 檢測**
  1. **富士山馬拉松之途 TATTA RUN (夏季錦標賽) 啟動**：8/8 開始的半馬線上累積賽，將在週六 the **20km LSD** 戶外跑中一次性完成近乎 95% 的進度。此賽事限制必須為 Garmin 戶外 GPS 記錄，切忌在跑步機上執行。
  2. **20km LSD 有氧耐力終極檢測**：週六安排的 20km LSD 是賽前最長距離的有氧耐力課表，旨在模擬雪梨馬拉松多起伏賽道的配速調整與高溫環境下的心率穩定度。
  3. **8km T 門檻耐受度鞏固**：週二質量日安排 12km T 門檻跑（含 8km T 區段，配速 6'07"/km），可在微幅起伏地形或跑步機（設定 1.5% 坡度）進行，加強雙腿在有乳酸堆積狀態下的推進效率與抗疲勞能力。

* **三、 關鍵課表：T門檻跑、20km LSD長跑與重訓三位一體**
  1. **週一 (08/03)**：5km Z1/Z2 恢復跑 + 上半身重訓。1km 暖身 + 3km 恢復慢跑 (HR: 134-153) + 1km 緩跑。跑後搭配上半身重訓與 10 分鐘睡前瑜伽。
  2. **週二 (08/04)**：12km T 門檻跑（2km 暖身 + **8km T配速 6'07"/km** + 2km 緩跑） + 跑者核心穩定訓練。睡前 10 分鐘放鬆瑜伽。
  3. **週四 (08/06)**：8km Z2 基礎有氧跑（1km 暖身 + 6km Z2 基礎有氧 + 1km 緩跑，跑步機設定 1.5-2.0% 坡度） + 下半身重訓。睡前 10 分鐘放鬆瑜伽。
  4. **週六 (08/08)**：20km LSD 戶外長跑（**必須戶外 GPS**，1km 暖身 + 18km Z2 有氧慢跑 + 1km 緩跑）。實地演練第 5km、10km、15km 定點補膠與補水，跑後 10 分鐘掛腿與深度拉伸。

* **四、 預期成效：乳酸轉運效率優化、下肢離心耐受度提升與腸胃高負荷吸收適應**
  1. **乳酸轉運與清除能力提升**：透過 8km T 門檻跑的持續刺激，誘導骨骼肌增加乳酸轉運蛋白表現，使身體在高強度運轉下具備更高的乳酸清除能力，為雪梨馬 Sub 4:30 奠定速度天花板。
  2. **下肢離心耐受度（抗下坡疲勞）提升**：透過週四的下肢阻力訓練（保加利亞分腿蹲、單腳硬舉）與週六 LSD 下坡技巧演練，提升股四頭肌的離心收縮控制力，應對雪梨馬連續下坡路段的衝擊。
  3. **腸胃道高負荷吸收適應**：20km 長跑中定點補膠與水分演練，可訓練小腸在運動血流重新分配時依然能高效吸收碳水化合物，防止比賽日發生腸胃不適。

* **五、 執行建議：嚴格執行起跑控速、手錶警示熔斷與步頻鎖定**
  1. **嚴格落實「起跑配速紀律」**：週六 LSD 前 3 公里強制將配速壓制在 **8'00" - 8'30"/km**，讓微血管網充分擴張，避免心率在起跑 20 分鐘內過載。
  2. **手錶心率熔斷機制**：將 Garmin 965 設定心率警報上限為 **166 bpm**。一旦警報響起，不論體感如何，必須立刻降低配速 15-30 秒/km，優先確保心率回到 Zone 2 有氧安全區間。
  3. **步頻鎖定防線**：跑步過程中將步頻鎖定在 **170-175 spm**，保持輕快落地的體感。高步頻能減少重心起伏，從而降低膝蓋和足底在起伏路面所承受的離心衝擊力。
