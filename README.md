# Running Garmin AI Coach - 專屬科學化訓練計畫書 (Wenchi)

## 1. 系統核心定位

Garmin AI Coach 是一個結合運動生理學、穿戴裝置數據分析與個人化動態課表排程的專業馬拉松訓練系統。本系統以「數據驅動，精確校準，無痛增長」為核心理念，每日自動讀取並解析跑者 Garmin 穿戴裝置數據（包括 `.fit` 運動檔案、靜息心率 RHR、身體能量 Body Battery、壓力指數 Stress、睡眠品質與 HRV 心率變異度等）。透過個人化動態跑力 (VDOT) 的精準校準，設定輕鬆跑 (E)、馬拉松配速 (M)、乳酸門檻 (T) 與間歇跑 (I) 之配速與心率區間，在生理超載刺激與超補償修復之間取得黃金平衡。系統同時具備防傷避險與疲勞監控機制，協助跑者在安全無痛的前提下超越極限，順利達成目標賽事完賽里程碑。

## 📅 4. 本週訓練重點 (W30)

本週（2026-07-20 ~ 2026-07-26）為「進展期後段 (W28-W30)」的第三週，即備戰雪梨馬拉松前最具考驗的**「高峰鞏固週 (Peak Phase)」**。本週課表在整體週期中扮演著承上啟下的核心角色，旨在鞏固過去六週累積的有氧底子，並透過實戰模擬建立對全馬後半段疲勞的抵抗力。以下為本週訓練的五大核心項目詳盡解析：

* **一、 訓練重點：高峰期的負荷累積與防禦性控速**
  本週為雪梨馬拉松備賽期跑量與強度最高的一週，預計總跑量達到 **41 公里**。訓練的核心邏輯在於「在安全受控的生理區間內完成最大里程刺激」。在上週暴露超速疲勞後，本週訓練重點明確轉向**「防禦性控速」**。平日的 5km 恢復跑與 8km 基礎有氧跑，務必嚴格將心率死鎖在 Zone 2 區間（153-166 bpm，134-153 bpm 尤佳），配速控制在 7'12"-8'02"/km。透過低強度、高步頻的連續刺激，擴充下肢肌群的毛細血管密度與線粒體數量，為週末長跑儲備體能。

* **二、 核心目標：17km 長跑補給實戰演練與門檻配速鎖定**
  1. **ONE TOKYO Global Virtual Race 4th 啟動與 17km LSD 戶外長跑**：本週六（07/25）配合虛擬賽啟動，安排 17km LSD 戶外跑（備賽單次最長里程突破）。必須全程在戶外 GPS 執行，實地演練雪梨馬拉松補給策略，於 6km 與 12km 定點補充能量膠與電解質，訓練胃部在高運動量下的吸收與排空能力。
  2. **嚴格門檻配速紀律 (Pacing Discipline)**：週二 11km T 門檻跑（含 7km 門檻區段）必須精準鎖定在 **6'07"/km**，嚴禁開頭暴衝。週一與週四輕鬆跑心率絕不可跨入 Zone 3。
  3. **模擬雪梨馬拉松坡度與風速**：雪梨 8 月清晨氣溫偏低且地形起伏顯著。戶外長跑時需選擇包含長緩坡的路線，演練「上坡縮短步幅維持 170+ 步頻、下坡順行放鬆保護股四頭肌」的節能跑法。

* **三、 關鍵課表：T門檻跑、LSD長跑與功能性肌力三位一體**
  1. **週二 11km T 門檻跑 (07/21)**：已執行 5.64km 跑步機 T 跑（均速 6'07"/km，主區段 5'45"-5'52"/km，步頻 174 spm），成功提升乳酸門檻配速巡航體感與心肺耐受度。
  2. **週四 8km Z2 基礎有氧跑 (07/23)**：已完成 8.00km 戶外跑（耗時 55m 21s，均速 6'55"/km，均心率 160 bpm），精準落入 Zone 2 有氧區間，鞏固血管與肌纖維耐力。
  3. **週六 17km LSD 戶外長跑 (07/25)**：1km Z1 暖身 + 15km Z2 有氧慢跑 (配速 7'12"-8'02"/km, 心率 153-166 bpm) + 1km Z1 緩跑。必須戶外執行並進行 6k/12k 補膠。
  4. **週日「長頸鹿」路跑賽事/導航探索 (07/26)**：完成 7.51km (1h 08m 08s，均心率 154 bpm Zone 2)，實測賽道體感與心率控制。
  5. **肌力與瑜伽輔助**：週一上半身重訓（臥推/划船）、週四下半身重訓（單腳硬舉/分腿蹲）、週五跑者功能性核心，搭配每日睡前 10-20 分鐘修復瑜伽。

* **四、 預期成效：乳酸清除率優化、跑步經濟性提升與抗疲勞轉化**
  1. **乳酸轉運能力提升**：透過 7km 乳酸門檻刺激，誘導骨骼肌增加乳酸轉運蛋白 (MCT1/MCT4) 表現，使身體在高強度運轉下具備更高的乳酸清除能力，為雪梨馬 Sub 4:30（6'23"/km）奠定速度天花板。
  2. **跑步經濟性 (Running Economy) 優化**：透過 170+ spm 高步頻引導，將觸地時間控制在 260ms 以下，降低垂直振幅與離心衝擊，提高每一步的動能回收效率。
  3. **胃部高負荷吸收適應**：長跑定點補膠演練可提高腸胃道對碳水化合物的轉運速率（SGLT1 載體活化），防止全馬後半段出現胃脹、噁心或血糖耗盡撞牆。

* **五、 執行建議：手錶雙警示設定、坡度心率守恆與睡前修復防線**
  1. **Garmin 手錶雙警示開啓**：跑前在 Garmin 965 設定「配速警示（E跑 7'12"-8'02"/km）」與「心率警示（Zone 2 上限 166 bpm）」。警示響起時立即放慢步伐。
  2. **上坡地形心率守恆**：戶外遇到上坡時，放棄配速執念，以「心率維持 Zone 2」為最高原則，縮短步幅、提升步頻順暢通過。
  3. **睡前修復瑜伽防線**：高峰週肌肉緊繃度極高，每日 22:00 前必須完成下犬式與鴿子式伸展，並於 23:00 前入睡，確保 Body Battery 充電品質。
