# Running Garmin AI Coach - 專屬科學化訓練計畫書 (Wenchi)

## 1. 系統核心定位

Garmin AI Coach 是一個結合運動生理學、穿戴裝置數據分析與個人化動態課表排程的專業馬拉松訓練系統。本系統以「數據驅動，精確校準，無痛增長」為核心理念，每日自動讀取並解析跑者 Garmin 穿戴裝置數據（包括 `.fit` 運動檔案、靜息心率 RHR、身體能量 Body Battery、壓力指數 Stress、睡眠品質與 HRV 心率變異度等）。透過個人化動態跑力 (VDOT) 的精準校準，設定輕鬆跑 (E)、馬拉松配速 (M)、乳酸門檻 (T) 與間歇跑 (I) 之配速與心率區間，在生理超載刺激與超補償修復之間取得黃金平衡。系統同時具備防傷避險與疲勞監控機制，協助跑者在安全無痛的前提下超越極限，順利達成目標賽事完賽里程碑。

## 📅 4. 本週訓練重點 (W31)

本週（2026-07-27 ~ 2026-08-02）為「2026 第 W31 週」，正式開啟雪梨馬拉松備戰的**「巔峰挑戰期第一週 (Peak Phase 1)」**。本週課表在整體 16 週週期中扮演著突破耐力極限與奠定速度適應力的雙重骨幹角色。以下為本週訓練的五大核心項目詳盡解析：

* **一、 訓練重點：巔峰挑戰期的負荷累積與高耐力抗疲勞**
  本週為雪梨馬拉松備賽進入最後 5 週衝刺的第一個高強度訓練週。訓練核心在於「在穩定控速與心率安全的前提下，完成單週高質量里程的突破與累積」。經歷上週賽事測試後，本週重點明確要求**「高耐力抗疲勞與紀律控速」**。週一的 5km 恢復跑與週四的 8km 基礎有氧跑，必須嚴格鎖定在 Zone 2 輕鬆區間（153-166 bpm，配速 7'12"-8'02"/km），透過高步頻 (170+ spm) 與低心率的連續刺激，進一步拓寬下肢毛細血管密度與線粒體有氧能量供給，為週末長跑打下無痛耐勞的基底。

* **二、 核心目標：ONE TOKYO 線上半馬完賽與 12km T 門檻跑挑戰**
  1. **ONE TOKYO Global Virtual Race 4th 完賽衝刺**：本週日（8/2 17:00 JST）前必須完成線上半馬 (21.0975km) 挑戰。週六安排的 **18km LSD 戶外長跑** 是主力骨幹，剩餘的 3.1km 可透過平日恢復跑輕鬆在 Strava/Garmin 上累計達標。全程必須**戶外 GPS 記錄**。
  2. **12km T 門檻跑挑戰（含 8km 門檻區段）**：週二質量日安排 12km T 跑，主課段包含 **8km T 配速區段 (精準標記 6'07"/km，HR: 171-180 bpm)**。這是考驗乳酸門檻耐受度與意志力的關鍵課表，要求全程專注於「維持 170+ 步頻」與「上半身放鬆」。
  3. **ONE TOKYO 線上主活動 10km 啟動**：8/1 開始之第三階段線上主活動挑戰 10km，週六 18km LSD 將直接一次性達標，提前鎖定 2027 東京馬拉松抽籤資格。

* **三、 關鍵課表：T門檻跑、18km LSD長跑與重訓三位一體**
  1. **週一 5km Z1/Z2 恢復跑 + 上半身重訓 (07/27)**：1km Z1 暖身 + 3km Z1/Z2 恢復慢跑 (HR: 134-153) + 1km 緩跑。跑後進行臥推與擺臂肌群強化重訓，睡前 10 分鐘瑜伽。
  2. **週二 12km T 門檻跑 + 跑者核心 (07/28)**：2km Z1/Z2 暖身 + **8km T 配速區段 (6'07"/km, HR: 171-180)** + 2km Z1 緩跑。跑後進行 30 分鐘徒手跑者功能性核心訓練。
  3. **週四 8km Z2 基礎有氧跑 + 下半身重訓 (07/30)**：1km Z1 暖身 + 6km Z2 基礎有氧 (HR: 153-166, 配速 7'12"-8'02"/km) + 1km 緩跑。跑後執行單腳硬舉與分腿蹲重訓。
  4. **週六 18km LSD 戶外長跑 (08/01)**：**必須戶外 (GPS)**。1km Z1 暖身 + 16km Z2 有氧慢跑 (HR: 153-166, 配速: 7'12"-8'02"/km) + 1km 緩跑。實地演練每 6km 定點補膠與水分。
  5. **週三、五、日 完全休息日**：安排深度修復瑜伽與靠牆掛腿，促進超補償。

* **四、 預期成效：乳酸清除效率優化、跑步經濟性提升與胃部高負荷適應**
  1. **乳酸轉運與清除能力提升**：透過 8km 乳酸門檻刺激，誘導骨骼肌增加乳酸轉運蛋白 (MCT1/MCT4) 表現，使身體在高強度運轉下具備更高的乳酸清除能力，為雪梨馬 Sub 4:30（6'23"/km）奠定速度天花板。
  2. **跑步經濟性 (Running Economy) 優化**：透過 170+ spm 高步頻引導，將觸地時間控制在 260ms 以下，降低垂直振幅與離心衝擊，提高每一步的動能回收效率。
  3. **腸胃道高負荷吸收適應**：18km 長跑定點補膠演練可提高腸胃道對碳水化合物的轉運速率（SGLT1 載體活化），防止全馬後半段出現胃脹、噁心或血糖耗盡撞牆。

* **五、 執行建議：手錶雙警示設定、水電解質補充與坡度技巧**
  1. **Garmin 手錶雙警示設定**：跑前在 Garmin 965 設定「配速警示（E跑 7'12"-8'02"/km）」與「心率警示（Zone 2 上限 166 bpm）」。警示響起時立即放慢步伐。
  2. **高溫汗水與電解質補充**：8 月氣溫偏高，跑前跑後測量體重，每流失 0.5kg 體重補充 500-750ml 水分，並適時補充電解質錠。
  3. **模擬雪梨馬拉松下坡技巧**：週六 18km LSD 後半段練習微幅下坡跑法，利用重力前傾、不刻意煞車，減輕股四頭肌衝擊負荷。睡前堅持執行 10-15 分鐘修復瑜伽與掛腿。
